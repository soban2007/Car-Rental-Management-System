# Car Rental Management System

A JavaFX-based desktop application for managing vehicle rentals, customers, rentals, reports, and admin authentication.

## Features

- Customer management
- Vehicle management
- Rental creation and history tracking
- Reports and analytics
- Admin login and authentication
- JavaFX desktop UI

## Tech Stack

- Java
- JavaFX
- Git

## Project Structure

- `src/` - Java source files and JavaFX views
- `data/` - local data files for customers, vehicles, admins, and rental records
- `bin/` - compiled project output

## How to Run

1. Open the project in Eclipse or another Java IDE.
2. Ensure JavaFX support is configured.
3. Run the main class:
   - `src/app/Main.java`
