# 🚗 Car Rental Management System

A desktop-based **Car Rental Management System** developed using **Java and JavaFX** as a 2nd Semester Software Engineering project.

The system is designed to manage vehicles, customers, rentals, payments, and other essential operations of a car rental business through a user-friendly graphical interface.

---

## 📌 Project Description

The **Car Rental Management System** is a JavaFX-based desktop application developed to provide an organized and efficient way to manage a car rental business.

The application allows administrators to manage vehicles and customers, maintain rental records, handle payments, and view useful information through a centralized dashboard.

This project demonstrates practical implementation of **Object-Oriented Programming (OOP)**, **JavaFX GUI development**, **FXML**, **CSS**, **file handling**, and **MVC architecture**.

## 🏗️ Architecture

The project follows an **MVC (Model-View-Controller)** based structure.

```text
Model
  ↓
Business/Data Logic
  ↓
Controller
  ↓
FXML / JavaFX View
```

### Main Components

* **Model** — Represents application data and entities.
* **View** — JavaFX/FXML user interface.
* **Controller** — Handles user interactions and application logic.
* **Repository** — Handles file-based data operations.
* **Service** — Contains business logic.
* **Util** — Contains reusable utility classes.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/soban2007/Car-Rental-Management-System.git
```

### 2. Open the Project

Open the cloned project in **Eclipse IDE**.

### 3. Configure Java

Make sure **JDK 21** is configured.

### 4. Configure JavaFX

Add **JavaFX 21** libraries to the project and configure the required VM arguments.

### 5. Run the Application

Run the main class:

```text
Main.java
```

The Car Rental Management System will launch.
